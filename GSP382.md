# GSP382 – Mitigate Threats and Vulnerabilities with Security Command Center: Challenge Lab

## Task 1 – Configure the environment (console)

Security > Security Command Center > Findings > time range: Last 180 days. Keep it on 180 days in every SCC screen.

## Setup

```
gcloud config get project > ~/project
echo scc-export-bucket-`cat ~/project` > ~/bucket
cat ~/project ~/bucket
```

## Block 1 – Static mute rules

```
gcloud scc muteconfigs create muting-flow-log-findings --project=`cat ~/project` --location=global --type=static --description="Rule for muting VPC Flow Logs" --filter='category="FLOW_LOGS_DISABLED"'
gcloud scc muteconfigs create muting-audit-logging-findings --project=`cat ~/project` --location=global --type=static --description="Rule for muting audit logs" --filter='category="AUDIT_LOGGING_DISABLED"'
gcloud scc muteconfigs create muting-admin-sa-findings --project=`cat ~/project` --location=global --type=static --description="Rule for muting admin service account findings" --filter='category="ADMIN_SERVICE_ACCOUNT"'
gcloud scc muteconfigs list --project=`cat ~/project` --location=global
```

Check my progress: Create static mute rules for Cymbal Bank

## Block 2 – Close the open SSH and RDP ports

```
gcloud compute firewall-rules list --format="table(name,sourceRanges.list(),allowed[].map().firewall_rule().list())"
gcloud compute firewall-rules update default-allow-ssh --source-ranges=35.235.240.0/20
gcloud compute firewall-rules update default-allow-rdp --source-ranges=35.235.240.0/20
gcloud compute firewall-rules list --format="table(name,sourceRanges.list(),allowed[].map().firewall_rule().list())"
```

If your rule names differ, use the names shown in the first list for tcp:22 and tcp:3389.

Check my progress: Fix Cymbal Bank's high vulnerability findings

## Block 3 – Static IP for cls-vm

```
gcloud compute instances list --filter="name=cls-vm" --format="value(zone.basename())" > ~/zone
gcloud compute zones describe `cat ~/zone` --format="value(region.basename())" > ~/region
gcloud compute instances describe cls-vm --zone=`cat ~/zone` --format="value(networkInterfaces[0].accessConfigs[0].natIP)" > ~/vmip
gcloud compute addresses create static-ip --addresses=`cat ~/vmip` --region=`cat ~/region`
gcloud compute addresses list
echo http://`cat ~/vmip`:8080
```

Open the URL in a new tab and confirm the Cymbal Bank portal loads.

## Block 4 – Run a Web Security Scan

```
gcloud services enable websecurityscanner.googleapis.com
gcloud alpha web-security-scanner scan-configs create --display-name=cymbal-scan --starting-urls=http://`cat ~/vmip`:8080
gcloud alpha web-security-scanner scan-configs list --format="value(name)" > ~/scanconfig
gcloud alpha web-security-scanner scan-runs start `cat ~/scanconfig`
```

Check my progress: Run a Web Security Scan

## Block 5 – Export findings to Cloud Storage

```
gcloud storage buckets create gs://`cat ~/bucket` --location=us-central1
gcloud scc findings list projects/`cat ~/project` --format=json | jq -c '.[]' > ~/findings.jsonl
gcloud storage cp ~/findings.jsonl gs://`cat ~/bucket`/findings.jsonl
gcloud storage ls gs://`cat ~/bucket`
```

If the check doesn't pass, use the console instead: SCC > Findings > time range All time > Export > Cloud Storage > choose the bucket, filename findings.jsonl, format JSONL.
